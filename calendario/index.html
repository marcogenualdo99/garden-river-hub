Importa arrivi da file agenzia

Carica il file .xls/.xlsx che ricevi dall'agenzia: le prenotazioni già presenti (stesso ID prenotazione) vengono riconosciute e saltate automaticamente, quelle nuove ti vengono mostrate qui prima di essere importate — nulla viene scritto finché non confermi.

Esporta documenti

Stesso formato del Report Famiglie già usato in Ristorazione — il file si apre pronto per la stampa.

Ospiti da censire (Alloggiati Web)

Per salvare la prenotazione basta il Capofamiglia/Ospite singolo (richiede documento). Gli altri Familiari vanno aggiunti e completati solo qui, prima di generare la schedina — a quel punto devono essere tanti quante le persone in prenotazione.

Documenti

Carica, visualizza o stampa i documenti legati a questa prenotazione (documento d'identità, contratto, ricevute...). Serve aver salvato la prenotazione almeno una volta.

Anteprima schedina Alloggiati Web
Bozza: nessuna chiamata reale viene effettuata. I codici (comune/stato/documento) sono testo libero — la mappatura ai codici ufficiali Alloggiati Web verrà completata quando collegheremo l'invio automatico.
